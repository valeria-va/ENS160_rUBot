# Mobile Robot eCO₂ Mapping
ROS 2 Humble project for indoor eCO₂ mapping using a mobile mecanum robot equipped with an array of ENS160 sensors. The robot uses SLAM and Nav2 to navigate through a room, collect the sensor readings and associate them with the robot pose. The recorded data can then be processed to generate spatial heatmaps or visualize the eCO2 levels live in RViz.
